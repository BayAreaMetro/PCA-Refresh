
# PCA Evaluation Tool

This project contains a Jupyter Notebook (`pca_evaluation_tool.ipynb`) that performs Spatial Overlay Analysis for Evaluation of the Priority Conservation Areas (PCA) using helper functions from `utils.py`. The inputs are read locally from the `_data` directory, and the output files are saved locally to the `evaluation_assignments` subdirectory.

## Setup Instructions

### 1. Create a Conda Environment

First, create a Conda environment using the `environment.yml` file:

```sh
conda env create -f environment.yml
```

### 2. Activate the Conda Environment

Activate the Conda environment:

```sh
conda activate pca-env
```

### 3. Install Jupyter Notebook

If Jupyter Notebook is not already installed, you can install it using Conda:

```sh
conda install jupyter
```

## Running the PCA Evaluation Tool

### 1. Start the Jupyter Notebook Server

Start the Jupyter Notebook server:

```sh
jupyter notebook
```

### 2. Open and Run the Notebook

Open the `pca_evaluation_tool.ipynb` file in the Jupyter interface and run the cells to perform the PCA evaluation.

## Directory Structure

- **_data**: This directory contains the input data files.
- **_data/evaluation_assignments**: This directory will contain the output files generated by the PCA evaluation tool.

## Additional Information

For more details on how PCA works and the dataset used, please refer to the comments and markdown cells within the Jupyter Notebook.
